# 💼 FinanceBot
FinanceBot — Telegram-бот для ведения личного бюджета прямо в мессенджере. Помогает отслеживать доходы и расходы, видеть текущий баланс и анализировать, на что уходят деньги.
Всё управление через удобные inline-кнопки — никаких команд запоминать не нужно. Добавил трату, выбрал категорию, написал заметку — готово. В любой момент можно открыть статистику и увидеть полную картину своих финансов.
Возможности

Учёт доходов и расходов по категориям
История транзакций с фильтрацией по месяцу и типу
Статистика с разбивкой трат по категориям
Удаление ошибочно добавленных записей
Данные хранятся локально — никуда не отправляются

Стек
Python 3.10+ · python-telegram-bot · JSON-хранилище

## 🚀 Установка и запуск

### 1. Получи токен бота

1. Открой Telegram, найди [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`, задай имя и username
3. Скопируй токен вида `1234567890:AABBcc...`

### 2. Настрой окружение

```bash
# Клонируй / скачай файлы проекта, затем:
cd finance_bot

# Установи зависимости
pip install -r requirements.txt

# Создай файл .env
cp .env.example .env
# Открой .env и вставь свой токен вместо заглушки
```

### 3. Запусти бота

```bash
python bot.py
```

Бот запустится в режиме polling — будет слушать сообщения в реальном времени.

---

## 💬 Как устроен бот

- **Главное меню** — inline-кнопки, всегда с текущим балансом
- **Диалоги** (ConversationHandler) — пошаговый ввод без путаницы
- **Данные** — хранятся в `transactions.json` рядом с ботом
- **Архитектура** — логика в `finance_core.py`, Telegram-код в `bot.py`
